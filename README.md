# 🌤️ Sky‑Clock – Weather & Time App

Sky‑Clock is a **Flutter‑based mobile application** that provides **real‑time weather updates** and **global time zone conversions**.  
It’s designed with a modern UI, offline caching, and supports both **Android** and **iOS** platforms.

---

## ✨ Features

✅ **Real‑Time Weather Updates**  
Get accurate current weather data and forecasts via integrated APIs.

✅ **Global Time Zone Conversion**  
Easily convert and view the current time in different time zones.

✅ **Dark Mode UI**  
User‑friendly dark mode for better usability in low‑light environments.

✅ **Offline Caching**  
Access previously fetched weather data and time info even without an internet connection.

✅ **Cross‑Platform Support**  
Built with **Flutter**, optimized for both Android and iOS.

## 📦 Installation & Running the App

### Prerequisites
- Install [Flutter SDK](https://flutter.dev/docs/get-started/install)
- Ensure you have Android Studio or Xcode installed for device emulators.

### Steps
```bash
# 1. Clone the repository
git clone https://github.com/benji181/SkyClock.git
cd SkyClock

# 2. Install dependencies
flutter pub get

# 3. Run the app on your emulator or device
flutter run
